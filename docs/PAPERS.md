# Every guidance method in the catalog

The pack's nodes come from a catalog of classifier-free guidance methods: 265 records (232 distinct methods; the rest are the same method seen from another line), each checked against its primary source. This page lists all of them with where they stand in the pack: a node now, planned for a later wave, or not a sampler method (training, language models, evaluation). Wave 2 needs new machinery (a second model, attention maps, feature patches, per-step state or fitted tables); wave 3 is sampler nodes, where the guidance sits inside the solver step.
